App de Seguimiento de Hábitos:



Proyecto realizado para el curso de Programación Avanzada.



La aplicación permite llevar un seguimiento de hábitos diarios. Cada usuario puede iniciar sesión y marcar cuando completa un hábito usando el botón Done, lo que va aumentando su racha de días y actualizando una barra de progreso.



Demo online:



La aplicación se puede ver funcionando aquí:



https://habitosapp-beta.vercel.app



&#x20;Tecnologías usadas



\* Node.js

\* Express

\* Next.js

\* Redux

\* TailwindCSS



Estructura del proyecto:



El proyecto está dividido en dos partes:



backend:



Contiene el servidor hecho con Node.js y Express.



frontend:



Contiene la interfaz hecha con Next.js y TailwindCSS.



Instalación:



1\. Clonar el repositorio



git clone https://github.com/Josbarck/habitos-app.git



2\. Instalar dependencias del backend



cd backend

npm install



3\. Ejecutar el backend



node server.js



4\. Instalar dependencias del frontend



cd frontend

npm install



5\. Ejecutar el frontend



npm run dev



6\. Abrir en el navegador



http://localhost:3000



Funciones principales:



\* Lista de hábitos

\* Login

\* Registro de usuarios

\* Botón Done para marcar hábitos como completados

\* Seguimiento de racha de días

\* Barra de progreso según hábitos completados
